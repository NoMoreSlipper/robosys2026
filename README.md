# robosys2026

![test](https://github.com/NoMoreSlipper/robosys2026/actions/workflows/test.yml/badge.svg)

ロボットシステム学2026の課題で作成したコマンド集です。
どちらのコマンドも、標準入力から読み取って標準出力へ書き出すフィルタ型のコマンドです。

## plusコマンド

標準入力から読み込んだ数字をすべて足して出力します。

```sh
$ seq 5 | ./plus
15
```

- 整数と小数の両方に対応します。
- 数値に変換できない行が含まれていると、終了ステータス 1 で異常終了します。

## lipoコマンド

LiPo（リチウムポリマー）バッテリーの電圧から、残量の目安を推定するコマンドです。
ロボットやラジコンで「このバッテリー、あとどれくらい使える？」を確認したいときに使います。

標準入力から電圧 [V] を1行に1つ読み取り、1行ごとに結果を標準出力へ書き出します。

```sh
$ cat voltages.txt | ./lipo
11.10 V → 3セル（1セル 3.70 V）残量 約30%
22.95 V → 6セル（1セル 3.82 V）残量 約56% / 保管に適した電圧
3.20 V → 1セル（1セル 3.20 V）残量 約0% / 過放電のおそれ（直ちに充電してください）
-- まとめ: 3件 / 1セル最低 3.20 V / 平均残量 約29% / 過放電 1件
```

### 機能

- セル数は電圧から自動判定します（1セル最大 4.20 V と仮定）。
  `--cells N` オプションでセル数を固定することもできます。
- 残量は「静置時の1セル電圧 → 残量」の対応表（4.20 V = 100%、3.70 V = 30%、
  3.30 V = 0% など）を線形補間して推定します。LiPoの放電特性は直線ではないため、
  単純な比例計算ではなくテーブルを使っています。
- 状態判定も行います：1セル 3.30 V 未満は「過放電のおそれ」、
  4.25 V 超は「過充電のおそれ」、3.78〜3.88 V は「保管に適した電圧」など。
- `11.1V` のような末尾の `V` や、`#` で始まるコメント行・空行も扱えます。
- 数値として読めない行は標準エラーに警告を出して読み飛ばします。
  有効な電圧が1件もなければ終了ステータス 1 で終わります。
- 2件以上入力すると、最後に要約（件数・1セル最低電圧・平均残量・過放電の件数）を表示します。

### 注意

- 残量は静置電圧（負荷をかけていない状態）をもとにした**目安**です。
  モーター駆動中など負荷がかかっているときの電圧では低めに出ます。
- バッテリーの個体差や劣化によってもずれます。過放電の警告が出たら
  速やかに充電してください。

## インストール

```sh
$ git clone https://github.com/NoMoreSlipper/robosys2026.git
$ cd robosys2026
```

クローンしたフォルダの中で、各コマンドを直接実行できます（インストール作業は不要です）。

```sh
$ seq 5 | ./plus
$ echo 11.1 | ./lipo
```

## 必要なソフトウェア

- Python
  - テスト済みバージョン: 3.10〜3.14
  - `test_lipo.py` の実行には pytest が必要です

## テスト環境

- Ubuntu 24.04 LTS
- GitHub Actions（Ubuntu / Python 3.10〜3.14）でも push のたびに自動でテストが実行されます

## テストの実行方法

```sh
$ bash ./test.bash        # plus と lipo の入出力テスト
$ python3 -m pytest -q    # lipo の単体テスト・入出力テスト
```
